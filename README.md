# Restaurant Hub
Sistema transaccional para la gestión de pedidos y pagos de un restaurante.

## Descripción
Restaurant Hub es un proyecto orientado al diseño de un sistema que permita organizar y gestionar la información relacionada con los pedidos, productos, clientes y pagos de un restaurante.
El proyecto busca representar una solución estructurada para facilitar el registro, seguimiento y control de las operaciones del restaurante.

## Estado del proyecto
Actualmente se encuentra en la etapa inicial de diseño y prototipado de la interfaz.

## Tecnologías utilizadas
- HTML5
- CSS3

## Estructura inicial
- `index.html` — Página principal del sistema.
- `css/styles.css` — Estilos de la interfaz.
